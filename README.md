# esxi-mcp

MCP (Model Context Protocol) server for VMware ESXi hypervisor management.

AI agents can query ESXi hosts, manage virtual machines, monitor datastores, and retrieve performance metrics via the MCP protocol.

## Status

🚧 Under active development.

## Planned Features

- Host information and health status
- VM list, power state, and basic management
- Datastore capacity and usage
- Performance metrics (CPU, memory, network, disk)
- Event/task monitoring
