编写一个 pyvmomi VSphere API 连接测试脚本。放在 esxi-mcp 项目根目录下，文件名 test_vsphere_connectivity.py。

## 测试目标
逐台测试 172.16.0.x 网段的 ESXi 宿主，确认 vSphere API（443端口）是否可达，以及认证是否通过。

## 脚本要求

1. **连接参数**：
   - ssl.SSLContext 设置不验证证书（ESXi 5.1 自签名证书）
   - 连接超时 15 秒
   - 端口 443

2. **每台主机测试流程**：
   a. 先测试 TCP 443 端口是否可达（socket connect，超时 5 秒）
   b. 如果 TCP 不通 → 输出 "TCP 不通" 并跳过
   c. 如果 TCP 通 → 用 pyvmomi 尝试连接：
      - 先试密码 zkgillion368
      - 密码错误则试 zkGillion@368
      - 认证成功后获取主机名和版本（AboutInfo）
      - 列出该主机上的虚拟机数量和名称列表
   d. 输出格式每台一行，先显示进度再汇总

3. **汇总输出**（最终打印清晰的表格）：
   ```
   主机              状态          版本          密码            虚拟机数
   172.16.0.192     TCP不通       -            -               -
   172.16.0.193     ✓ 连接成功    ESXi 5.1.0   zkgillion368    5
   172.16.0.194     ✓ 连接成功    ESXi 5.1.0   zkgillion368    8
   172.16.0.195     TCP不通       -            -               -
   ...
   ```

4. **依赖**：使用项目的 .venv（已有 pyvmomi），运行命令：
   `.venv/bin/python test_vsphere_connectivity.py`

5. **要求**：
   - 端口检测失败不要报 traceback，优雅处理
   - pyvmomi 连接失败捕获异常并输出原因（不报 traceback）
   - 最后 exit code: 0（不要因为某台失败而退出非0）
