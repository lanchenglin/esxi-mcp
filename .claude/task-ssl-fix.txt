修改 test_vsphere_connectivity.py，修复 ESXi 5.1 SSL 兼容性问题。

当前脚本用 ssl.PROTOCOL_TLS_CLIENT，这对 ESXi 5.1 不兼容（5.1 只支持 TLS 1.0/SSLv3）。VMware 客户端内置兼容层所以能连上，但 pyvmomi 需要手动配置。


改动要求：

1. SSL 兼容性
   - 创建一个函数，尝试多种 SSL 配置：先用 PROTOCOL_TLS_CLIENT（兼容新版 ESXi），失败后降级到 PROTOCOL_TLSv1，再失败降到 PROTOCOL_SSLv23
   - 在所有配置中都设置 check_hostname=False, verify_mode=CERT_NONE
   - 可能需要设置 cipher string 允许弱加密套件

2. 区分错误类型（重要！目前 except Exception 笼统返回 "认证失败"，分不清是 SSL 握手还是密码错误）
   - SSL 握手异常（ssl.SSLError, ConnectionRefusedError, socket.timeout 等）→ 输出 "SSL握手失败" 
   - pyVmomi 登录失败（vim.fault.InvalidLogin）→ 输出 "密码错误"
   - 其他 vim.fault → 输出具体错误信息

3. 对 172.16.0.193 和 172.16.0.194 两台已知 ESXi 5.1，密码只试 zkgillion368 即可（SSH 已确认），对其他的两个密码都试

4. 运行测试：.venv/bin/python test_vsphere_connectivity.py

修复后应该能连上 193 和 194（ESXi 5.1），以及 192/195/200/172 中的某些。
